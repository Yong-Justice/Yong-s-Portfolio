# Portfolio content checklist

The website deliberately leaves the following items unresolved until verified source material or permission is available.

- [ ] `TODO_GITHUB_PROFILE_URL` — exact GitHub profile URL
- [ ] `TODO_NEXACASE_LIVE_AND_REPOSITORY_URLS` — confirmed live and public repository URLs
- [ ] `TODO_ARKIVA_LIVE_AND_REPOSITORY_URLS` — confirmed live and public repository URLs
- [ ] `TODO_PROJECT_SCREENSHOTS` — approved desktop, mobile, workflow, captions, and accurate alt text
- [ ] `TODO_PERMISSION_CLIENT_PROJECT` — written permission status for the German examination platform
- [ ] `TODO_FORMALIO_PROJECT_DETAILS` — verified purpose, role, status, dates, stack, links, and publishable evidence
- [ ] `TODO_AUTHORISED_PORTRAIT` — replace the watermarked source with a photographer-authorized clean export
- [ ] `TODO_FINAL_CV_PDFS` — verify the supplied 2026 English and French PDFs are final before launch
- [ ] `TODO_CUSTOM_DOMAIN` — optional final domain and `NEXT_PUBLIC_SITE_URL`

## Release checks

- Confirm every live/repository URL before changing a project status to live.
- Use fictional data in NexaCase and Arkiva screenshots.
- Never publish client credentials, user/payment data, private administration screens, proprietary exam content, or client source code.
- Run the full quality checklist in the README before each public release.
